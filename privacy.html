Privacy Policy - Outlook Calendar Sync

Last updated: 2026

What the app does

Outlook Calendar Sync is a personal tool that reads events from Google Calendars that the developer owns or that were shared with him, and copies them into Outlook on the developer's own computer.

Data accessed

The app requests the read-only scope https://www.googleapis.com/auth/calendar.readonly to read calendar events (title, time, location, description).

How data is used and stored

  • Calendar data is used only to create events in Outlook on the same computer.
  • Temporary files and the OAuth login token are stored locally on that computer only.
  • No data is sent to any server operated by the developer or to any third party.
  • No data is sold, shared, or used for advertising.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

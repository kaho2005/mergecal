Outlook Calendar Sync

Outlook Calendar Sync is a small personal tool that copies events from the Google Calendars of its developer and his family into Outlook on his own computer, once per day.

The tool runs only on the developer's local machine. It uses the Google Calendar API with read-only access (calendar.readonly). It is not offered to the public and has no user accounts or servers.
